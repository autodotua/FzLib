# FzLib

## `Application`

| 类名                        |                        | 描述                                                         | 备注 |
| --------------------------- | ---------------------- | ------------------------------------------------------------ | ---- |
| `ApplicationInfo`           | 应用程序信息与重启控制 | 提供应用程序运行时的关键信息与控制功能，能够获取程序路径、名称、所在目录及当前工作目录，并支持将工作目录重置为程序目录。该类还提供安全的重启机制，可在指定延迟后重新启动应用，常用于配置变更或更新安装场景。 |      |
| `IdentityProvider`          | 生成用户与设备唯一标识 | 用于生成跨平台的用户与设备唯一标识，通过系统底层信息（如注册表、machine-id、MAC 地址、用户 SID/UID 等）综合生成稳定可靠的机器码与用户码，并支持持久化保存。该类可用于区分不同设备和用户，实现身份识别、授权或统计等功能。 |      |
| `UnhandledExceptionCatcher` | 全局异常捕获与处理     | 提供统一的全局异常捕获机制，支持捕获来自任务、线程和 UI 的未处理异常，并通过构建器模式灵活配置异常处理逻辑与最终执行步骤。该类可帮助应用在非调试模式下安全地捕获和记录异常，防止程序意外崩溃，提高整体稳定性。 |      |

## `Application.Startup`

提供跨平台的应用自启动管理功能，通过统一接口 `IStartupManager` 抽象启用、禁用及检测启动项的方法，并分别在 Windows、Linux 与 macOS 上提供对应实现。`WindowsStartupManager` 通过修改注册表实现启动项管理，`UnixStartupManager` 则利用 `~/.config/autostart` 下的 `.desktop` 文件控制启动项；配套的 `StartupManagerExtensions` 提供依赖注入与便捷调用支持，使应用能够在不同操作系统上以一致方式实现开机自启。

| `TwoWayDictionary`    | 双向字典     | 一个双向字典实现，既可以通过键查找值，也可以通过值查找键。它内部维护正向和反向字典，保证键值唯一性，并实现了 `IDictionary<TKey, TValue>` 接口，适用于需要双向映射和快速互查的场景。 |      |

## `IO.Pipes`

提供了基于命名管道的简单客户端和服务端封装，`SimplePipeServer` 支持异步发送消息并自动处理连接与断开，`SimplePipeClient` 可异步接收消息并通过事件通知订阅者，结合取消令牌实现可中断的消息传输，使进程间通信在 .NET 环境下简单、安全且易于集成。
